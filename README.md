# Photoschool

Programma di fotoritocco e disegno nel browser, per le classi della Scuola Secondaria di I grado
R. Montecuccoli (Pavullo nel Frignano). Funziona senza installare nulla.

È una versione adattata di **PhotoCraft** (software libero, licenza MIT o Apache-2.0).

approvato da esso; i loghi ArtCraft sono stati tolti. Le note di licenza originali sono nei file
`LICENSE-MIT`, `LICENSE-APACHE` e `NOTICE`.

Il sito si pubblica da solo su GitHub Pages a ogni modifica (`.github/workflows/pages.yml`).
